Opis szczegółowy

Widget prezentujący szczegółowe informacje o zawodniku.

Wyświetla:

  • Dane osobowe i pozycja
  • Statystyki sezonowe (gole, asysty, kartki, minuty)
  • Historia kontuzji i zawieszenia
  • Trend warości statystyk
