◆ generateSchedule()

void LeagueEngine::generateSchedule ( )

Generuje terminarz round-robin (mecz i rewanz) dla parzystej liczby druzyn.

Gwarantuje, ze kazda para druzyn spotyka sie dokladnie dwa razy (u siebie i na wyjezdzie), a kazda druzyna rozgrywa 2*(n-1) meczow.
